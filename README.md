# Sim Sim no Mi: releases

The builds of Sim Sim no Mi, a One Piece Card Game simulator: the Android APK, the Windows installer and portable exe, macOS and Linux, and the card pack.
The apps check this repo for updates and always ask before they download anything.
Each release has a signed manifest (opsim-update.json) with every file's SHA-256; the apps refuse any file that does not match it.
